# Features.md

## Admin Features

| Feature | Status |
|---|---|
| Secure admin login (username/password) | MVP |
| Create / edit / delete categories | MVP |
| Create / edit / delete items | MVP |
| Upload multiple images per item, set a primary image, reorder images | MVP |
| Set item fields: name, price, description, material, dimensions, color/variant options, stock status, warranty, delivery info | MVP |
| Toggle item active/hidden (soft-hide without deleting) | MVP |
| Manage shop info: address, map embed link, phone, WhatsApp number, opening hours, About text | MVP |
| View & manage contact form submissions | MVP |
| Mark item as "Featured" for homepage display | MVP |
| Basic image compression/validation on upload | MVP |
| Bulk category/item ordering (drag-and-drop display order) | Future |
| Multi-admin roles with granular permissions | Future |
| Analytics dashboard (most-viewed items) | Future |
| CSV import/export of catalog | Future |

## Customer-Facing Features

| Feature | Status |
|---|---|
| Homepage with featured items and category shortcuts | MVP |
| Shop dropdown/menu listing all categories | MVP |
| Category listing page (grid of items with image, name, price) | MVP |
| Item detail page: name, price, multiple images, description, material, dimensions, color/variant options, stock status, warranty, delivery info | MVP |
| Mobile-friendly image gallery/carousel on item detail page | MVP |
| Collapsible/hamburger navigation on mobile & tablet | MVP |
| Responsive grid layouts (columns adjust by breakpoint) | MVP |
| About page | MVP |
| Contact page: phone (click-to-call), WhatsApp link, contact form, address, embedded map, opening hours | MVP |
| "In stock / Out of stock" badge on listings and detail page | MVP |
| Trust badges (e.g., "5 Year Warranty," "Free Delivery & Installation") | MVP |
| Search bar (by item name) | Future |
| Filter/sort on category page (price, material, color) | Future |
| Wishlist (session-based, no login) | Future |
| Product reviews/ratings | Future |
| Related/similar items on detail page | Future |

## Shop Info Features

| Feature | Status |
|---|---|
| Store address with embedded Google Map | MVP |
| Phone number (click-to-call on mobile) | MVP |
| WhatsApp click-to-chat link | MVP |
| Opening hours display (per-day, with open/closed today indicator) | MVP |
| Contact form (name, phone/email, message) stored for admin review | MVP |
| Social media links (Instagram/Facebook) | Future |
| Multiple store branch listings | Future |

> **Non-negotiable constraint:** All customer-facing pages must be fully responsive and touch-friendly across mobile (<768px), tablet (768–1024px), and desktop (>1024px). This applies to every MVP feature above, not just "not broken" rendering.
